# 超分台

**把满意的构图留下，把想补的细节说清楚。**

超分台是面向网页与 ChatGPT Work 的 AI 图像超分与细节增强工具。选一张图，指定需要丰富的区域和需要保留的内容，再以更大的尺寸生成结果。你可以在网页里直接操作，也可以先和 Work 中的 agent 商量方案，再确认生成。

它采用生成式增强，适合插画、概念图和 AI 创作的二次细化；输出可能重新解释原图细节，并非逐像素保真的放大。

[快速开始](#快速开始) · [使用指南](docs/USAGE.md) · [Work 工作流](WORK-GUIDE.md) · [部署指南](AGENT-DEPLOY.md)

## 功能

- **按意图增强**：分别描述增强区域和严格保留项，减少笼统提示词带来的偏移。
- **直观控制尺寸**：默认 2 倍；上传后计算合法倍率范围，拖动滑块即可查看实际输出宽高。
- **两种操作入口**：网页逐单确认；Work 先读图、给出方案与尺寸，得到确认后提交。
- **原图与结果对照**：默认拖线对比；单图模式支持滚轮缩放、按住拖动，切换原图与结果时保留查看位置。
- **完整 PNG 交付**：保留生成尺寸，不额外裁切；网页保存原文件，Work 校验后发送原生附件。
- **任务与历史管理**：查看进度、结果和本次用量费用估算；网页与 Work 共用历史，每页 10 条，可启用最近 50 条保留。

默认由 **GPT-6.1 Terra** 协调、**Sunburst** 生成图像；需要速度优先时可选择 **Flare**。

## 使用流程

### 在网页中

1. 点击上传或拖入 PNG / JPG。
2. 填写增强要求，选择倍率，查看实际输出尺寸。
3. 点击“生成”，核对本单参数与费用说明后确认。
4. 等待完成，对照原图检查细节，点击“保存到本地”。

### 在 Work 中

把选定图片交给 agent，并调用超分台。例如：

> 放大到 2 倍，丰富背景飞船的结构和星空细节；保留人物的脸、姿势、服装和整体构图。先告诉我输出尺寸与增强方案，确认后再生成。

agent 会读取原文件的实际尺寸，检查倍率是否可用，并整理增强内容、保留项、模型与费用确认单。需求已经明确时直接沿用，不重复询问；完成后返回一张原 PNG 和本次用量估算。详细约定见 [Work 使用指南](WORK-GUIDE.md)。

## 快速开始

### 部署使用

需要支持 **Sites / Work 插件**的 ChatGPT 环境，以及可调用所需模型的 OpenAI API 项目。后端使用 Worker ESM、D1 和 R2。

1. [下载源码 ZIP](https://github.com/underzark/chaofentai/archive/refs/heads/main.zip)，或克隆仓库。
2. 将 [部署指南](AGENT-DEPLOY.md) 交给具备 Sites 能力的 agent，完成站点、存储和 MCP 插件配置。
3. 在站点的服务端 secret 设置中配置一次 API key，完成无费用检查后开启使用。

图像生成与协调模型会产生 API 费用；每单先确认，完成后显示用量估算。价格计算与未知用量的处理见 [费用说明](COST-BASIS.md)。

### 本地开发预览

使用 Node.js 24。根目录测试和构建不需要安装依赖：

```sh
git clone https://github.com/underzark/chaofentai.git
cd chaofentai

npm test
npm run build
npm run validate
node scripts/preview.mjs
```

打开 `http://127.0.0.1:43824`。本地预览使用内存存储和模拟身份，关闭生成，不会调用收费 API；云端部署步骤见上面的部署指南。Worker 运行时测试见 [TESTING.md](TESTING.md)。

## 适用范围

适合在已有画面基础上丰富材质、环境和背景细节，或将满意的 AI 创作继续放大细化。文字、面部与微小结构可能变化，应对照原图检查；不适合需要准确还原原始信息的证据、测量或文档识别场景。

倍率受模型尺寸限制，2 倍不可用时会显示可选范围。输入格式、历史淘汰规则和浏览器保存兼容性见 [使用指南](docs/USAGE.md)。
