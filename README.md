# 超分台

把已有图片交给 AI，在放大输出的同时丰富指定区域的细节。支持网页操作，也支持 ChatGPT Work 中先讨论、确认，再生成并取回原 PNG。

这是**生成式重绘与细节增强**，不是无损超分或严格保真的传统算法。模型可能改变纹理、小字或人物细节，请检查结果；不适合需要证据级还原的用途。

## 能做什么
- 网页上传 PNG / JPG，选择倍率，查看实际输出尺寸；确认本单费用后生成。
- 默认 GPT-6.1 Terra 协调、Sunburst 生图；明确需要速度时可选 Flare。
- 原图 / 结果 / 拖线对比，缩放查看，保存一张完整原 PNG。
- Work 读取真实文件尺寸、规划增强与保留项，逐单确认后提交；返回原 PNG 和用量费用估算。
- 私有历史最多保留最近 50 条可淘汰记录，支持分页查看。

## 自己部署
本仓库只提供通用代码，不提供作者的站点、账号或 API。每位使用者需在支持 Sites 的 ChatGPT 环境创建自己的 **owner-private Site**，配置自己的 OpenAI API。公开代码不代表私人站点公开，也不保证所有账号均支持 Sites / Work。

请把 [AGENT-DEPLOY.md](AGENT-DEPLOY.md) 交给具有 Sites 能力的 agent。它需要读取当时的官方 Sites 技能，创建独立 Site，绑定 D1 / R2 / MCP，完成无费用验证，再由你决定开启使用。不能只运行 npm install 就得到托管服务。

本地验证（Node 24；根目录无需安装依赖）：
```sh
npm test
npm run build
npm run validate
node scripts/preview.mjs
```
预览仅监听 127.0.0.1:43824，使用内存模拟身份/存储，生成关闭；不是生产身份或持久存储验证。更多测试见 [TESTING.md](TESTING.md)。

## 费用与边界
API 图像调用和协调模型均可能收费，与 ChatGPT 订阅/托管费用分开。每单先确认；结束后按返回用量和价格快照估算，**不是最终账单，也不是硬性上限**。未知用量显示未知，不假报零。见 [COST-BASIS.md](COST-BASIS.md)。部署时须核对官方当前价格和账号资格。

输入上限 8 MiB。普通正向 baseline JPEG 最多 20MP、单边 8192；需解码的旋转/渐进 JPEG 最多 2MP，且可能因 24MiB 解码预算拒绝。ICC 与旋转组合、后置 EXIF/ICC 等不支持。允许受限二进制尾部的 JPEG 会保留原件，只无损去尾生成模型输入，不重新有损压缩。不是任意损坏 JPEG 修复器。

输出受模型尺寸/像素/比例限制，默认 2 倍不一定可用；以权威计划返回尺寸为准。新任务不裁边。模型支持和价格可变化；不能把既有环境的验收视为你的副本已通过。

启用 50 条保留后，未来新增任务会淘汰最早符合条件的历史及无其他引用的原图/成品，**不可恢复**。在途、未知提交、共享引用及安全幂等记录受保护，因此不是精确磁盘配额，也不保证总占用只有 1GB。重要文件请先下载。

网页只有一个“保存到本地”原文件链接。内嵌浏览器普通点击可能受宿主限制；桌面可右键“将链接另存为”。移动设备仅在支持时提供系统分享/保存，不能绕过系统权限直接写相册。当前 ChatGPT Windows 内嵌普通点击仍待用户验收，不能把按钮状态变化当保存成功。
