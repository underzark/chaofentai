# 使用指南

[返回首页](../README.md)

## 选择原文件

支持 PNG、JPG / JPEG，输入文件上限 8 MiB。JPG 与 JPEG 是同一格式的不同扩展名；服务端根据实际字节验证，改扩展名不能转换文件。

| JPEG 类型 | 当前边界 |
| --- | --- |
| 正向、无需解码的 baseline JPEG | 最多 20MP，单边最多 8192 |
| 需要方向纠正或解码的渐进 JPEG | 最多 2MP，并受 24MiB 解码预算约束 |
| 同时带 ICC 色彩配置与非正向 EXIF | 当前拒绝，建议先导出方向正确的 PNG |
| 扫描段后的 EXIF / ICC | 当前拒绝 |

低于像素上限也可能触发解码资源限制。普通正向 JPEG 保留压缩数据和色彩配置直接使用；少量符合安全规则的二进制尾部会无损移除后作为输入，原件仍保留。这不是损坏图片修复功能。

上传失败时查看简短原因，必要时展开或复制诊断。不要通过重复改后缀、伪造文件类型解决错误。

## 倍率与输出尺寸

默认倍率为 2 倍。上传后，工具按模型的边长、总像素、比例和尺寸对齐要求计算可用范围；实际输出宽高以页面或规划工具返回值为准。

如果 2 倍超出范围，需要选择可用倍率。Work agent 应先说明上限与对应尺寸，不能默默缩小后仍称为 2 倍。输出保留一张完整生成 PNG，不再额外裁边。

## 确认与费用

网页点击“生成”后先准备本单报价，再弹出确认；取消不会提交生成。Work 同样先展示原图、增强与保留项、倍率和实际尺寸、模型、数量一张及费用说明，等待明确确认。参数变化需重新确认。

结束后的费用依据返回的协调模型和图像工具用量计算，属于美元消耗估算，不是最终账单或硬性封顶。缺失用量显示未知或不完整，不当作零。详细计算见 [COST-BASIS.md](../COST-BASIS.md)。

任务状态不明时，不要换任务标识重复提交。先检查原任务状态；单 owner 的在途或未知任务会阻止新生成，以降低重复收费风险。

## 查看与保存

对比模式以完整画面适配，左原图、右结果，只拖动分界线。需要检查局部细节时切换单图模式，使用缩放与平移。原图显示放大只是便于比较，并不表示增加了原始细节。

网页“保存到本地”保留真实原文件链接。桌面内嵌浏览器普通点击可能受宿主限制，可尝试右键“将链接另存为”。支持文件分享的触控环境可准备文件后再次点击打开系统分享；是否出现保存选项取决于浏览器与系统。Windows ChatGPT 内嵌普通点击和 iPhone 系统分享仍需实际设备验收，不能保证所有宿主行为一致。

Work 通过受保护工具读取文件，在执行环境重组并检查长度与 SHA256 后，使用支持的 Library 通道发送原生附件。完整流程见 [WORK-GUIDE.md](../WORK-GUIDE.md)。

## 历史与保留

网页和 Work 共用历史。网页每页 10 条，只加载当前页缩略图。

启用最近 50 条保留后，未来新增任务会淘汰最早符合条件的记录，并删除不再被其他任务引用的原图和成品；删除不可恢复，请提前下载重要文件。在途、未知任务、共享引用和防重复收费记录受保护，因此该策略不是严格的磁盘容量上限。未提交的上传文件也可能占用空间。

## 反馈问题

可在 [Issues](https://github.com/underzark/chaofentai/issues) 提供复现步骤、浏览器环境与脱敏后的错误信息。不要附 API key、认证信息或不希望公开的图片。
